# TongDaRailway Mod 通达铁路

这是一个添加自动生成机械动力铁路的模组

**此模组只维护1.21.1 NeoForge版本，无其他版本适配计划！**

**模组更新修改地形生成时，使用老版本模组的世界在删除已生成的非必要区块前，请勿更新新版本模组**

## 1.1.0 更新路线生成算法

* 路线图大致生成步骤：
* 使用低差异序列在区域内随机均匀的选择站点
* 去除不合法的选点（如海洋上的点）
* 将站点连接成为德劳内三角网
* 删边，使得圆周上的相邻边在特定角度以上
* 删边，使得节点的最大度为4。根据节点度数分配对应出口的车站
* 返回节点和它所连接的所有节点
* 通过匈牙利匹配为每个车站出口匹配一条边
* 根据匹配结果生成连接
* 现在只有某些区域会生成铁路。有些区域则有概率不生成铁路
### 寻路范围

在当前生成区域内，仅以已匹配双出口的路网边（站点间线段）构造边 Voronoi（最近邻）区域，未匹配或仅匹配单出口的边不参与划分。每条路线只允许在其原始路网边对应的区域内寻路：区域内的点到该边的水平最短距离不大于到任何其他参与划分的路网边的距离，等距边界由相邻区域共享。

寻路起终点、每次步进的整条线段以及最后连接终点的一步都受此约束。若车站出口偏移后的起终点不在对应区域内，或该区域内无可用路径，则跳过该连接并记录日志。

几何回归测试可通过 `gradlew.bat testEdgeVoronoi` 运行，也包含在 `check` 中。
